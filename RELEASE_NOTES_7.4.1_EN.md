# Telegram Desktop 7.4.1 with Jalali Calendar — First Stable Release

This release is based on Telegram Desktop 7.4.1 and follows the upstream version number.

## Added

- Dates of received and sent messages in private chats, groups, and channels are displayed using the Jalali calendar.
- The date picker displays Jalali months, years, and days.
- Dates use day–month–year order.
- This release is packaged for Linux only.

## Installation

Extract the archive and run the `Telegram` executable. The `Updater` file is included alongside it.
